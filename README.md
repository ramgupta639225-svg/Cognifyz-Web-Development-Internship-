# Cognifyz Web Development Internship

This repository contains the tasks and projects completed during my **Web Development Internship at Cognifyz Technologies**.

The internship focused on building practical web development skills through HTML, CSS, JavaScript, responsive design, and frontend frameworks.

## Internship Tasks

### Level 1

#### Task 1 – HTML & CSS

* Created a basic webpage using HTML and CSS.
* Added a heading, paragraph, and image.
* Created a basic form with an input field and submit button.
* Designed a simple navigation menu with three links.

#### Task 2 – JavaScript

* Created a button that changes color when clicked.
* Implemented a time-based greeting alert using JavaScript.
* Built a basic calculator to add two numbers and display the result.

### Level 2

#### Task 1 – Frontend Frameworks

* Created a responsive card component using a frontend framework.
* Implemented a responsive grid layout using a frontend framework.

#### Task 2 – Responsive Design

* Converted a webpage into a responsive layout using CSS media queries.
* Created a mobile-friendly navigation menu with a hamburger menu.

### Level 3

#### Task 1 – Image Manipulation

* Created an image gallery with clickable thumbnails.
* Implemented an automatic image slideshow.

#### Task 2 – Landing Page

* Created a landing page for the Cognifyz Web Developer Internship.
* Added internship introduction, highlights, qualifications, CTA, and contact information.
